# Workbook fonts

Source Sans 3 Regular and Bold are bundled for the revised workbook pages.
They are distributed under the SIL Open Font License 1.1 in [OFL.md](OFL.md).
The font binaries are third-party assets, not covered by the repository's MIT grant.

Downloaded from Adobe's source-sans repository on 29 September 2026:

- [Regular](https://raw.githubusercontent.com/adobe-fonts/source-sans/release/TTF/SourceSans3-Regular.ttf)
- [Bold](https://raw.githubusercontent.com/adobe-fonts/source-sans/release/TTF/SourceSans3-Bold.ttf)
- [Licence](https://raw.githubusercontent.com/adobe-fonts/source-sans/release/LICENSE.md)

The original PDF supplies the Flamong logo and retains its embedded fonts on unchanged pages. Revised code blocks use the standard PDF Courier font.
